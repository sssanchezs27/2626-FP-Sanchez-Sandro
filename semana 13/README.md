# Semana 13 - Función para calcular total de compra

Estudiante: Sanchez Sandro

Este proyecto resuelve un problema cotidiano de una tienda: calcular el total de una compra en función del precio de un producto y la cantidad solicitada por el cliente. La lógica está estructurada en una función con dos parámetros y devuelve el resultado con `return`.

## Archivo principal
- `calcular_total_compra.py`

## Cómo ejecutar
1. Abre una terminal.
2. Navega a la carpeta `semana 13`.
3. Ejecuta el siguiente comando:

```bash
python calcular_total_compra.py
```

## Resultado esperado
El programa mostrará el total de la compra en consola.
